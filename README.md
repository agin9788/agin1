# 游戏工具合集
## 项目简介
纯原生HTML+CSS+JS开发的机械风导航主页，分为小游戏、实用工具、益智三类，全页面动画+机械点击音效，适配手机/电脑，无任何第三方依赖。

## 功能
- 🎮 小游戏：俄罗斯方块、连连看、恐龙跳跃、多款飞行小游戏
- 🛠️ 实用工具：颜色表、进制换算、单位换算、计算器、音乐播放器
- 🧩 益智游戏：24点、数独、推箱子等

## 页面特色
1. 标题彩虹流光动画、背景网格纹理、自转齿轮装饰
2. 点击音效：按键音、机械换挡音、金属撞击音（代码生成，无音频文件）
3. 卡片悬浮扫光、点击水波纹、手机震动反馈
4. 两种切换方式：顶部标签切换 / 点击标题自动轮换分类

## 使用教程
1. 本地运行：直接双击 `index.html` 用浏览器打开
2. 部署：全部html上传静态服务器即可访问网页
3. 手机：文件发送手机，浏览器打开
